# 📘 Гайд 1. Работа с файлами и правила поведения в терминале

**Цель:** Научиться уверенно перемещаться по файловой системе, находить нужные файлы (логи, конфиги) и безопасно выполнять базовые операции, не полагаясь на графический интерфейс.

---

## 🛑 Часть 1. «Золотые правила» выживания в терминале

Прежде чем мы начнем вводить команды, запомните три правила, которые сэкономят вам нервы и время:

1. **`Tab` — ваш лучший друг.** Никогда не вводите длинные имена файлов или пути вручную. Начните вводить название и нажмите `Tab`. Система сама допишет его. Если вариантов несколько, нажмите `Tab` дважды, и система покажет список.
2. **`Ctrl+C` — кнопка «Паника».** Если команда зависла, вы ввели что-то не то, или процесс выполняется бесконечно — нажмите `Ctrl+C`. Это прервет выполнение текущей команды и вернет вам управление.
3. **`Ctrl+R` — поиск по истории.** Не нужно стрелкой вверх листать 100 команд назад, чтобы найти ту самую длинную команду, которую вы вводили вчера. Нажмите `Ctrl+R`, начните вводить часть команды, и терминал сам её найдет. Нажмите `Enter`, чтобы выполнить.

## 🧭 Часть 2. Навигация: Где я и куда идти?

В Linux нет дисков `C:` или `D:`. Есть единое дерево каталогов, начинающееся с корня `/`.

### 1. Где я сейчас нахожусь?
```bash
pwd
```
*(Print Working Directory). Покажет абсолютный путь от корня. Например, `/var/log`. Запомните эту команду, если потерялись.*

### 2. Что здесь находится?
```bash
ls
```
Покажет список файлов. Но нам нужны «суперспособности» (флаги):
```bash
ls -la
```
*   `-l` (long) — выводит подробный список: права доступа, владельца, размер и дату изменения.
*   `-a` (all) — показывает **скрытые** файлы (те, что начинаются с точки, например `.bashrc`). Конфиги часто скрыты!

```bash
ls -lh
```
*   `-h` (human-readable) — показывает размеры файлов в КБ, МБ, ГБ, а не в байтах.
*💡 **Идеальная комбинация для сисадмина:** `ls -lah` (показывает всё, подробно и в понятных размерах).*

### 3. Как перемещаться?
```bash
cd /var/log          # Перейти в конкретную папку (абсолютный путь)
cd nginx             # Перейти в папку nginx внутри текущей (относительный путь)
cd ..                # Шагнуть на один уровень ВВЕРХ (в родительскую папку)
cd ~                 # Вернуться в свою домашнюю папку (обычно /home/username)
cd                   # Аналогично cd ~, просто вернуться домой
```

## 🛠 Часть 3. Базовые операции с файлами

### 1. Создание
```bash
touch test.txt       # Создать пустой файл
mkdir new_folder     # Создать папку
mkdir -p a/b/c       # Создать цепочку папок (a, внутри неё b, внутри b -> c). Флаг `-p` очень удобен, не ругается, если папка уже есть.
```

### 2. Копирование и Перемещение
```bash
cp file1.txt file2.txt   # Скопировать файл
cp -r folder1 folder2    # Скопировать папку (флаг `-r` означает рекурсивно, т.е. со всем содержимым)

mv old_name.txt new_name.txt  # Переименовать файл
mv file.txt /tmp/             # Переместить файл в /tmp
```

### 3. Удаление (ВНИМАНИЕ! ⚠️)
```bash
rm file.txt          # Удалить файл
rm -r folder/        # Удалить папку и её содержимое
```

> 🚨 **ПРАВИЛО ОСТОРОЖНОСТИ:** Команда `rm -rf /путь/` удаляет всё без вопросов и без корзины. В Linux **нет корзины** в терминале. Удаленное `rm` восстановить крайне сложно (а чаще всего невозможно).
> *Никогда не копируйте слепо команды `rm -rf` из интернета. Всегда проверяйте путь, который вы собираетесь удалять, дважды.*

## 👁 Часть 4. Чтение файлов (Как посмотреть, что внутри)

Вам часто придется читать конфиги и логи. Открывать их в `nano` только для чтения — плохая практика (можно случайно изменить и сохранить). Используйте команды просмотра:

### 1. `cat` — «вывалить» всё содержимое
```bash
cat config.txt
```
*Хорошо для маленьких файлов. **Плохо** для логов на 100 МБ — терминал просто «захлебнется» и улетит в космос.*

### 2. `less` — умный просмотрщик (Pager)
```bash
less huge_log.log
```
*Открывает файл постранично.*
*   `Пробел` или `PageDown` — листать вниз.
*   `b` — листать вверх.
*   `/текст` — найти слово (например, `/ERROR`). Нажимайте `n`, чтобы искать следующее совпадение.
*   **`q`** — выйти из просмотра.

### 3. `head` и `tail` — начало и конец
```bash
head -n 20 file.log  # Показать первые 20 строк
tail -n 50 file.log  # Показать последние 50 строк
```

### 4. `tail -f` — Режим реального времени (Магия!)
```bash
tail -f /var/log/syslog
```
Флаг `-f` (follow) заставляет команду не закрываться, а **показывать новые строки по мере их появления**.
*Как использовать:* Запускаете `tail -f` на лог, в другом окне (или на компьютере врача) воспроизводите ошибку. Смотрите, что упало в терминал.
*Как остановить:* Нажмите `Ctrl+C`.

## 🏥 Практический кейс: «У врачей не сохраняется карта в МИС»

**Легенда:** Вам поступает заявка. Врачи в приемном покое жалуются, что при сохранении электронной карты пациента МИС (Медицинская Информационная Система) выдает ошибку. Вы зашли по SSH на сервер приложений МИС.

**Ваши действия по Гайду 1:**

1. **Понять, где мы и где логи.**
   ```bash
   pwd
   # Вывод: /home/admin
   cd /var/log/mis/
   ```

2. **Найти свежий лог.** Нам нужен файл, который менялся сегодня. Сортируем по времени изменения (`-t`), новые сверху.
   ```bash
   ls -lht
   # Вывод покажет что-то вроде:
   # -rw-r--r-- 1 mis mis 45M Oct  6 14:22 mis-app-2026-10-06.log
   # -rw-r--r-- 1 mis mis 80M Oct  5 23:59 mis-app-2026-10-05.log
   ```
   *Видим, что актуальный файл — `mis-app-2026-10-06.log`.*

3. **Посмотреть последние 50 строк**, чтобы увидеть, чем закончилась последняя операция (возможно, там уже видна причина).
   ```bash
   tail -n 50 mis-app-2026-10-06.log
   ```

4. **Перейти в режим реального времени**, чтобы поймать ошибку в моменте.
   ```bash
   tail -f mis-app-2026-10-06.log
   ```
   *(Просим врача попробовать сохранить карту еще раз. Смотрим, какие красные строки с `ERROR` или `Exception` посыпались в терминал. Копируем их для передачи разработчикам. Жмем `Ctrl+C`, чтобы выйти).*
